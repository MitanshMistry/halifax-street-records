About this site

Who made this?

This independent project summarizes grouped totals from HRM's public data. HRM does not run it. It cannot look up individual requests and does not receive or forward reports.

The public link to the project code and contact details are not set up in this preview yet.

Report an error on this site

This preview does not have a public way to send feedback yet. A verified contact or project-code issue link must be added before publication. Do not include street addresses, coordinates, request IDs, or personal details in an error report.

To report a road problem, use HRM’s 311 service. This site cannot send a report for you.
